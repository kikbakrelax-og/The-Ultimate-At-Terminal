hayes AT command set — origin (1977–1981, Hayes Microcomputer Products)
The Hayes Smartmodem command set is the foundation everything else is built on. All subsequent AT command extensions — GSM, CDMA, LTE — inherit the Hayes syntax and session model.

AT — attention prefix. Every command starts here. The modem checks for ATdt in the receive buffer at all times.
ATZ — reset modem to stored user profile (NVRAM). Does not restore factory defaults.
AT&F — restore factory defaults. Does not save — combine with AT&W to persist.
AT&W — write current settings to active user profile in NVRAM.
ATE0/ATE1 — echo disable/enable. E0 stops modem echoing your commands back, useful for scripting.
ATV0/ATV1 — result code format. V0=numeric (0=OK,1=CONNECT,2=RING,3=NO CARRIER,4=ERROR), V1=verbose text.
ATQ0/ATQ1 — result code suppression. Q1 silences all result codes entirely.
ATX0–X4 — result code set selection. X4 enables full extended result codes including connect speed.
ATH0/ATH1 — hook control. H0=on-hook (hangup), H1=off-hook (pick up line).
ATA — answer incoming call immediately.
ATO — return to online data mode from command mode (opposite of +++)
AT+++ — escape sequence. Pause-plus-plus-plus-pause returns to command mode during a call without hanging up. Guard time default 1 second each side.
ATD — dial. ATDTnumber (tone), ATDPnumber (pulse), ATDL (redial last), ATD; (dial without going online).
ATL0–L3 — speaker volume: 0=off, 1=low, 2=medium, 3=high.
ATM0–M2 — speaker mode: 0=always off, 1=on until carrier, 2=always on.
ATP / ATT — pulse / tone dialling selection.
AT&C0/C1 — DCD (carrier detect) pin behaviour. C1=follows actual carrier state.
AT&D0/D2 — DTR behaviour. D2=hangup and return to command mode when DTR drops.
AT&K0/K3 — flow control. K0=none, K3=RTS/CTS hardware flow control.
S-registers — the Hayes parameter store
S-registers are the original persistent parameter storage — the NV RAM concept of 1981.

ATS0=n — auto-answer after n rings. 0=disable.
ATS1? — ring counter (read-only, resets after timeout).
ATS2=43 — escape character (default 43 = ASCII '+').
ATS3=13 — command line terminator (default 13 = CR).
ATS4=10 — response format character (default 10 = LF).
ATS5=8 — command line edit (backspace) character.
ATS6=2 — wait for dial tone (seconds).
ATS7=60 — wait for carrier after dial (seconds). Connection timeout.
ATS10=14 — carrier loss disconnect delay (tenths of seconds).
ATS12=50 — escape guard time (fiftieths of a second each side of +++). Critical for timing attacks on the escape sequence.
lineage into GSM — what changed
GSM 07.07 (1994) took Hayes as the base and added the + namespace for extended commands. The original Hayes set remained intact for backwards compatibility — the same reason every GSM modem still responds to ATZ and AT&F today. This is the first layer of the architectural debt you're researching. The Hayes session model (command mode vs online data mode, DTR signalling, S-registers as NV) was never redesigned for cellular — it was shimmed on top.
ISO/IEC 7816-4 — interindustry APDU command set (1995)
The foundational spec. Every smart card, SIM, USIM, JavaCard, EMV card, and CAC card implements this. Every newer layer (GlobalPlatform, EMV, NFC/ISO 14443, ETSI TS 102.221) stacks on top.

APDU structure
Command APDU: CLA INS P1 P2 [Lc] [Data] [Le]
Response APDU: [Response Data] SW1 SW2

CLA — class byte: 00=ISO standard, 80/84=proprietary (GlobalPlatform), A0=GSM legacy, 0X=logical channel X
INS — instruction byte (the command)
P1 P2 — parameters / qualifiers
Lc — length of command data
Le — expected response length (00=max)
SW1 SW2 — status words: 90 00=OK, 61 XX=response available, 6C XX=wrong Le, 69 82=security not satisfied, 6A 82=file not found
core commands — CLA=00
00 A4 04 00 Lc AID — SELECT by AID (application ID). Used to select USIM, ISIM, or JavaCard applets.
00 A4 00 00 02 FID — SELECT by file ID (e.g. 3F00=MF, 7F10=DF_TELECOM, 7F20=DF_GSM, 7FFF=ADF_USIM)
00 B0 P1 P2 Le — READ BINARY. P1P2=offset into transparent EF.
00 D6 P1 P2 Lc Data — UPDATE BINARY. Write to transparent EF.
00 B2 Rec P2 Le — READ RECORD. P2: 02=next, 03=previous, 04=absolute.
00 DC Rec P2 Lc Data — UPDATE RECORD.
00 C0 00 00 Le — GET RESPONSE. Retrieve pending response data after 61 XX status.
00 20 00 01 Lc PIN — VERIFY (PIN). PIN padded with FF to 8 bytes.
00 24 00 01 Lc Data — CHANGE REFERENCE DATA (change PIN).
00 2C 00 01 Lc PUK+PIN — RESET RETRY COUNTER (PUK unblock).
00 70 00 00 01 — MANAGE CHANNEL open. Returns channel number.
00 70 80 CN — MANAGE CHANNEL close channel CN.
00 88 00 00 Lc RAND — INTERNAL AUTHENTICATE. Used in GSM/UMTS AKA.
00 CA 00 6F 00 — GET DATA tag 6F (card capabilities).
00 CA 9F 7F 00 — GET DATA CPLC (Card Production Life Cycle — manufacture/personalisation dates, IC serial).
00 F2 00 0C 00 — GET STATUS (current selected file info).
GlobalPlatform commands — CLA=80/84
80 CA 9F 7F 00 — GET DATA CPLC via GP namespace.
80 F2 80 00 02 4F00 — GET STATUS — Issuer Security Domain.
80 F2 40 00 02 4F00 — GET STATUS — all applications.
80 F2 20 00 02 4F00 — GET STATUS — executable load files.
84 E4 00 80 Lc AID — DELETE — remove applet or package. Requires secure channel (SCP02/SCP03).
84 E6 02 00 Lc Data — INSTALL [for install] — instantiate applet from loaded package.
84 E8 00 00 Lc Data — LOAD — transfer applet CAP file block.
key EF file identifiers (USIM)
3F00 = MF (master file)
7FFF = ADF_USIM
6F07 = EF_IMSI
6F46 = EF_SPN (service provider name)
6F30 = EF_PLMN (preferred PLMN selector)
6F78 = EF_ACC (access control class)
6F7E = EF_LOCI (location information — LAI, TMSI)
6F73 = EF_PSLOCI (PS location — P-TMSI, RAI)
6FE3 = EF_EPSLOCI (EPS location — GUTI, TAI)
6F38 = EF_UST (USIM service table)
6F3C = EF_SMS
6F40 = EF_MSISDN
6F31 = EF_HPPLMN (home PLMN search period)
6FAD = EF_AD (administrative data — MNC digit count, op mode)
status words — full decode
90 00 — success, no further data
61 XX — success, XX bytes of response available (GET RESPONSE needed)
62 XX — warning, state unchanged
63 CX — warning, X retries remaining (PIN verification failed)
69 82 — security status not satisfied (wrong key / channel / SCP state)
69 83 — authentication method blocked (PIN blocked, use PUK)
69 85 — conditions of use not satisfied (file not invalidated, wrong state)
6A 80 — incorrect parameters in data field
6A 82 — file or application not found
6A 84 — not enough memory space
6A 86 — incorrect P1 P2
6A 88 — referenced data not found
6C XX — wrong Le; XX is correct length to reissue with
6D 00 — instruction not supported
6E 00 — CLA not supported
6F 00 — unknown error
AT+CSIM usage — raw APDU via AT port
AT+CSIM=length,"hex_apdu"
length = total hex characters (bytes × 2)

Example — read EF_IMSI:
1. AT+CSIM=14,"00A4080C027FFF" — SELECT ADF_USIM
2. AT+CSIM=14,"00A4080C026F07" — SELECT EF_IMSI
3. AT+CSIM=10,"00B0000009" — READ BINARY 9 bytes
Response: +CSIM: 22,"08295001012143658709 9000"

AT+CGLA=channel,length,"hex_apdu" — same but on logical channel (opened via AT+CCHO or MANAGE CHANNEL)
sierra wireless — ! command set (EM/MC/WP modern series)
AT!ENTERCND="A710" — unlock extended command set. Required on carrier-locked firmware before most !cmds.
AT!GVER? — full firmware version string including bootloader, app layer, radio, build date.
AT!PRIID? — PRI (Product Release Instructions) ID identifying carrier variant and customisation tier.
AT!IMAGE? — firmware image slots. Useful for identifying downgrade paths.
AT!GSTATUS? — comprehensive single dump: RAT, RSSI, RSRP, RSRQ, SINR, band, EARFCN, PhyCellID, TAC, global CellID, DRX cycle, temp, IMS registration state.
AT!RSSI? — per-antenna RSSI and LTE RSRP/RSRQ breakdown.
AT!LTEINFO? — LTE physical layer: EARFCN, DL/UL BW, MIMO rank, MCS, BLER, PhyCellID, TAC, PLMN.
AT!LTECA? — carrier aggregation: PCell + SCell list, EARFCN, band, BW, RSRP per component carrier.
AT!BAND? / AT!BAND=mask,ltemask,tdscdma — query and lock RF band bitmask. 00=auto. Persists across resets. Requires AT!RESET after change.
AT!SELRAT? / AT!SELRAT=n — RAT mode: 00=auto, 02=UMTS, 03=LTE, 06=LTE+UMTS, 07=all.
AT!ANTSEL? — antenna selection state (diversity paths).
AT!DIVERSITY? / AT!TXDIVERSITY? — receive and transmit diversity configuration.
AT!LTEDISABLED? — query whether LTE capability has been disabled (carrier customisation).
AT!OPMODE? — operating mode (online, low power, factory test).
AT!PCTEMP? — PA and core die temperature in degrees C.
AT!PCVOLTAGE? — supply voltage in mV.
AT!USBCOMP? / AT!USBCOMP=n — USB composition: 0=DM+NMEA+AT+MBIM, 1=MBIM only, 8=ECM.
AT!NVBACKUP / AT!NVRESTORE / AT!NVDEFAULTS — NV backup, restore, factory reset. NVDEFAULTS is destructive and removes all carrier customisation.
AT!ROAMCONTROL? — roaming preference configuration.
AT!IMPREF? — IMS (VoLTE) registration preference.
AT!MSMSRATE? — SMS rate limiting configuration.
sierra HL / Q / RV — +W wavecom legacy (HL6, HL7, Q2686, Q2698, RV50)
AT+WIND? / AT+WIND=n — unsolicited event mask. Bit field: 0=SIM state, 1=registration, 4=call, 11=GPRS attach. e.g. 2050=0x0802=GPRS+reg.
AT+WDWL — DWL firmware flash mode via XMODEM on serial port. Non-recoverable without completing transfer.
AT+WOPEN? — Open-AT embedded application status: 0=stopped, 1=running.
AT+WHWV? — hardware PCB version string.
AT+WSVN? — internal software build ID.
AT+WIMI? — IMSI in Sierra HL namespace. Returns decoded MCC/MNC/MSIN.
AT+WMBS? / AT+WMBS=band,persist — band: 0=E-GSM 900/1800, 1=850/1900, 2=900/1900, 3=all. persist: 0=temp, 1=NV.
AT+CCED=0,1 — serving cell engineering dump: MCC,MNC,LAC,CellID,BSIC,ARFCN,RxLev,C1,C2,NMR.
AT+CCED=2,7 — serving + 6 neighbour cells in single response.
AT+WLCK="type",passwd,mcc,mnc — personalisation lock/unlock. Types: NET, SP, SIM, ORSP.
AT+WRIM? — ring indicator: 0=pulse on incoming, 1=hold during call.
AT+WCCS? — character set page: GSM, IRA, HEX.

ETSI TS 27.007 — extended AT commands (3GPP, evolved from GSM 07.07 1994)
AT+CFUN=n — functionality level. 0=minimum (RF off), 1=full, 4=disable TX/RX (airplane), 6=reset. Key for power/RF state research.
AT+CPWROFF — graceful power off. Not in all implementations; Sierra and Quectel support it.
AT+CIMI — IMSI from SIM EF_IMSI. 15 digits: MCC(3)+MNC(2-3)+MSIN.
AT+CRSM=cmd,fileid,p1,p2,p3[,data] — restricted SIM access. Wraps READ BINARY/RECORD and UPDATE at predefined EF paths. Safer than raw CSIM for common reads.
AT+CSIM=len,"hex" — generic SIM access. Sends raw APDU directly to SIM. Full 7816-4 access including proprietary commands.
AT+CGLA=channel,len,"hex" — generic logical channel access. Like CSIM but on a specific logical channel opened via CCHO or MANAGE CHANNEL.
AT+CCHO="AID" — open logical channel to application by AID. Returns channel number for use with CGLA.
AT+CCHC=channel — close logical channel.
AT+CUAD? — read UICC application discovery data. Lists all AIDs present on the card (USIM, ISIM, payment applets etc).
AT+CRLA=channel,cmd,fileid,p1,p2,p3[,data] — restricted logical channel access. Like CRSM but on specific channel.
AT+CIND? — read indicators: signal strength, battery, roaming, call, message, service availability.
AT+CMER=mode,keyp,disp,ind — mobile equipment event reporting. Enables URC indicators for display/keypad/indicator changes.
AT+COPN — read full operator name table from modem NV. Useful for PLMN decoding.
AT+CPOL? / AT+CPOL=index,format,oper — read/write preferred PLMN list in SIM EF_PLMN. Can add or remove preferred operators.
AT+CCLK? / AT+CCLK="yy/MM/dd,hh:mm:ss±zz" — read/set real-time clock.
AT+CTZU=1 — enable automatic time zone update from network NITZ messages.
AT+CTZR=1 — enable time zone change URC reporting.
AT+CGCONTRDP[=cid] — read dynamic PDP context parameters: IP address, gateway, DNS servers, MTU. Available after activation.
AT+CGPIAF=1,0,0,0 — IP address format control for IPv6 display.
AT+CGEREP=1,0 — GPRS event reporting: PDN activation/deactivation URCs.
STK / OTA — TS 31.111 and TS 102.221
AT+STKPRO — URC for proactive SIM commands (DISPLAY TEXT, SETUP MENU, SEND SMS, OPEN CHANNEL etc)
AT+STKCNF — terminal confirmation for STK commands requiring user interaction
AT+STKTR="hex" — send terminal response APDU back to SIM after proactive command
AT+STKENV="hex" — send envelope command to SIM (MENU SELECTION, EVENT DOWNLOAD, CALL CONTROL, SMS CONTROL)
OTA delivery path: Network → SMS-PP (TS 23.048) → SIM receives as APDU payload → SIM processes before host sees message → may trigger STK proactive command → AT+STKPRO URC appears
